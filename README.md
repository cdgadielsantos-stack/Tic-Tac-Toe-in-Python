# Tic-Tac-Toe em Python

Um projeto simples de **Jogo da Velha (Tic-Tac-Toe)** desenvolvido em Python para praticar lógica de programação, manipulação de matrizes, funções e estruturas de controle.

## Sobre o Projeto

Este projeto implementa uma versão do clássico **Jogo da Velha** executada diretamente pelo terminal. Dois jogadores alternam entre os símbolos **X** e **O**, escolhendo posições no tabuleiro até que um deles complete uma linha, coluna ou diagonal, ou até que ocorra um empate.

O principal objetivo deste projeto foi consolidar conhecimentos fundamentais da linguagem Python por meio da implementação completa da lógica do jogo.

---

## Funcionalidades

- ✅ Tabuleiro 3x3 exibido no terminal
- ✅ Alternância automática entre os jogadores
- ✅ Verificação de vitória por linhas
- ✅ Verificação de vitória por colunas
- ✅ Verificação de vitória por diagonais
- ✅ Detecção de empate
- ✅ Interface simples e intuitiva

## Regras do Jogo

- O jogador **X** inicia a partida.
- Cada jogador escolhe uma posição informando a linha e a coluna.
- Vence quem completar:
  - Uma linha inteira;
  - Uma coluna inteira;
  - Uma diagonal inteira.
- Caso todas as posições sejam preenchidas sem vencedor, ocorre empate.
